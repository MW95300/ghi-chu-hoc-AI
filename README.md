# ghi-chu-hoc-AI

Kho lưu trữ ghi chú, prompt và skill hỗ trợ học tập bằng AI.

## Skill làm video AI ngắn

Bộ hướng dẫn tạo video kể chuyện 30–60 giây cho YouTube Shorts và TikTok, chủ đề câu chuyện, triết lý hoặc lịch sử.

- [Quy trình và prompt tạo video](skills/video-ai-short-form/SKILL.md)
- [Mẫu storyboard, hồ sơ nhân vật, đạo cụ và bối cảnh](skills/video-ai-short-form/templates/storyboard-template.md)

Có hướng dẫn riêng để xây **hook 3 giây đầu** và duy trì nhất quán nhân vật, đạo cụ, bối cảnh qua các cảnh.
